# PocketMoney User Personas

## Adam — Solo Self-Hoster

**Role:** Primary user, sole administrator, and power user of PocketMoney  
**Goals:**
- Track personal expenses accurately with minimal manual effort
- Maintain full control over how transactions are categorized and labeled
- Be able to cross-reference app data with bank statements for reconciliation
- Leverage AI to reduce repetitive work, but always retain final say

**Pain Points:**
- Raw bank transaction names are messy and inconsistent across banks
- Pattern-based matching can be too broad, silently miscategorizing transactions
- Losing the original transaction name makes bank reconciliation difficult
- Fixing a categorization mistake requires manual effort with no retroactive correction

**Context:**
- Self-hosts the application (Supabase backend)
- Imports transactions via CSV/XLSX from bank exports
- Manages merchant aliases, categories, and rules personally
- Values transparency — wants to understand what the system did and why
- Comfortable with technical interfaces but prefers efficiency over complexity
